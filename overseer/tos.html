2. Service Description

Overseer is an AI-powered moderation bot for Discord servers. It analyzes messages using a large language model-based safety system to enforce server-defined moderation policies.

Features may be modified, added, or removed at any time without notice.

#

3. AI Moderation & Processing

All non-excluded messages in participating servers are processed using the server owner's Groq API key and the gpt-oss-safeguard:20b model.

Messages are evaluated against the server-defined moderation policy configured via the Bot.

#

4. Excluded Content Rules

  • Excluded channels & categories: Messages in excluded channels or categories are never sent to Groq and are not moderated.
  • Excluded roles: Messages from users with excluded roles are not directly moderated, but may be included as contextual information when evaluating surrounding messages.
  • Images & attachments: Image content is not analyzed or moderated.
#

5. Data Storage

The Bot stores the following data per server:

  • Server configuration (policy text, excluded channels/roles/categories)
  • Groq API key (stored in plaintext)
  • Appeals channel ID
  • Appeals rate limits
  • Synced server IDs
  • Moderation logs (permanently stored)
  • User violations (user IDs and flagged message content)

Moderation logs and violation records are stored indefinitely unless manually removed.

#

6. Third-Party AI Processing (Groq)

Messages that are subject to moderation are sent to Groq using the server owner's API key. Use of Groq is subject to Groq's own terms and privacy policies.

#

7. Ban Sync

The Bot supports cross-server ban synchronization between linked servers.

No persistent data is stored for ban sync beyond the list of linked server IDs. If a banned user is present in linked servers, the Bot will attempt to apply the ban automatically.

#

8. Appeals & False Positives

Appeals are sent to the configured appeals channel and include:

  • Original message content
  • AI moderation reasoning
  • Applied punishment

False positive reports submitted by users are sent to the Bot owner with full message context, username, and moderation reasoning.
