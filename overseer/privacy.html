#

1. Overview

Overseer ("the Bot") is an AI-powered moderation system for Discord servers. It analyzes messages using a large language model-based safety classifier to enforce server-defined moderation policies.

This Privacy Policy explains what data is collected, how it is used, and how it is stored.

#

2. Data Collected

The Bot may collect and store the following data depending on configuration:

  • Server configuration (moderation policy, excluded channels/roles/categories)
  • Discord user IDs
  • Discord server (guild) IDs
  • Channel and role IDs
  • Moderation decisions and violation records
  • Flagged message content (text only)

Images and attachments are not collected or analyzed.

#

3. Message Processing

Messages that are subject to moderation are sent to Groq using the server owner's API key for AI-based classification.

No data is used for AI training by Overseer.

#

4. Excluded Content

  • Excluded channels & categories: Messages in excluded channels or categories are NOT sent to Groq and are not processed.
  • Excluded roles: Messages from excluded roles are not directly moderated, but may be included as contextual information when evaluating nearby messages.
  • Images & attachments: Images and attachments are not processed or analyzed.
#

5. Data Storage

The Bot stores moderation-related data for functionality purposes:

  • Moderation logs (stored permanently)
  • User violations (including flagged message content and AI reasoning)
  • Server configuration data
  • Appeals data (until manually removed by server administrators)
  • Synced server IDs (for ban synchronization only)

Kicking or removing the Bot does NOT automatically delete stored data.

#

6. API Keys

Server-provided Groq API keys are stored in plaintext to enable message processing. These keys are used only for moderation requests initiated by the server.

Users are responsible for managing and rotating their API keys if needed.

#

7. Third-Party Services

Overseer uses Groq for AI message classification. Any data processed by Groq is subject to Groq’s own privacy policy and terms.

#

8. Appeals & Reports

When a user submits a false positive report or appeal, the following may be sent to the Bot owner:

  • Full message content
  • Discord username
  • Server ID
  • AI moderation reasoning
  • Applied punishment

Appeals submitted in servers are stored in the configured appeals channel until removed by server administrators.

#

9. Ban Synchronization

Ban sync operates without persistent user data storage.

Only linked server IDs are stored to enable cross-server ban propagation. No additional user profiling or history is kept for sync functionality.

#

10. Data Retention

  • Moderation logs: stored indefinitely
  • User violations: stored indefinitely
  • Appeals: stored until manually deleted
  • Server configuration: stored while bot is installed

There is currently no automatic data expiration system.

#

11. User Rights

Users may request data removal by contacting the bot owner. The primary method of removal is to request deletion directly from:

  • Email: omena0mc@gmail.com
  • Discord: @omena0

Removing the bot from a server does not automatically delete stored data, as it may be required for moderation history and safety logs.

#

12. Security

While reasonable measures are taken to secure stored data, no system can guarantee absolute security.

Server owners are responsible for safeguarding their own API keys.
